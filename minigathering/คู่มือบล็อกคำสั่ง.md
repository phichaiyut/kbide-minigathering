# คู่มือบล็อกคำสั่ง MiniGathering

สรุปคำอธิบายบล็อกลาก-วางทั้ง 8 หมวดหมู่ของบอร์ด MiniGathering ใน KBIDE ชื่อในกรอบ `code`
คือชื่อฟังก์ชัน/พารามิเตอร์จริงที่ปรากฏบนตัวบล็อก ตามด้วยคำอธิบายการใช้งาน

## เริ่มต้น (Setup)

บล็อกเริ่มต้นระบบ วางไว้บรรทัดแรก ๆ ของ Setup เสมอ

| บล็อก | คำอธิบาย |
| --- | --- |
| `robotsetup` | เริ่มต้นระบบของหุ่นยนต์ทั้งหมด — Serial, ปุ่ม, บัซเซอร์, มอเตอร์ **ต้องวางเป็นบล็อกแรกสุดเสมอ** ก่อนใช้บล็อก MiniGathering อื่นใด |
| `wait_start` | หยุดรอจนกว่าจะกดปุ่มเริ่ม ถ้ากดค้างเกิน 2 วินาทีจะเข้าสู่โหมดคาลิเบรตเซนเซอร์เส้นให้อัตโนมัติ |

## มอเตอร์ (Motor)

สั่งมอเตอร์ทั้งแบบมีหน่วงเวลาในตัว และแบบขับต่อเนื่องที่คืนค่าทันที ความเร็วทุกบล็อกอยู่ในช่วง -100 ถึง 100

| บล็อก | คำอธิบาย |
| --- | --- |
| `Motor  L  R` | สั่งมอเตอร์ซ้าย-ขวาพร้อมกัน ความเร็ว -100 (ถอยหลังสุด) ถึง 100 (เดินหน้าสุด) |
| `Motor1  spd` / `Motor2  spd` | สั่งมอเตอร์ข้างเดียว — Motor1 คือซ้าย, Motor2 คือขวา |
| `MotorStop` / `MotorStop  de` | หยุดมอเตอร์ทั้งสองข้างทันที รุ่นที่มีช่อง `de` จะหน่วงเวลาหลังหยุดตามมิลลิวินาทีที่กำหนดด้วย |
| `Move  l  r  de` | สั่งมอเตอร์ซ้าย-ขวา แล้วหน่วงเวลาตามที่กำหนด รวมในบล็อกเดียว |
| `fd / bk / sl / sr / tl / tr  speed` | ขับเคลื่อนต่อเนื่อง **ไม่หน่วงเวลา** คืนค่าทันที เหมาะกับใช้ในลูป — เดินหน้า / ถอยหลัง / หมุนซ้ายอยู่กับที่ / หมุนขวาอยู่กับที่ / เลี้ยวซ้ายล้อเดียว / เลี้ยวขวาล้อเดียว |
| `fd2 / bk2  speedL  speedR` | เดินหน้า/ถอยหลัง โดยกำหนดความเร็วซ้าย-ขวาแยกกันเอง ไม่หน่วงเวลาเช่นกัน |

## เสียง/ปุ่ม (Sound & Button)

ควบคุมบัซเซอร์และอ่านสถานะปุ่มกดบนบอร์ด

| บล็อก | คำอธิบาย |
| --- | --- |
| `beep` | บัซเซอร์ดังสั้น ๆ ประมาณ 50 มิลลิวินาที |
| `Beep  de` | บัซเซอร์ดังตามระยะเวลาที่กำหนด (มิลลิวินาที) |
| `BZon` / `BZoff` | เปิด/ปิดเสียงบัซเซอร์ค้างไว้ — ต้องใช้ BZon คู่กับ BZoff เสมอ |
| `fastBeep` | บัซเซอร์ดังสั้นมาก ประมาณ 15 มิลลิวินาที |
| `WaitOK` | หยุดรอจนกว่าจะกดปุ่ม แล้วบี๊บยืนยัน — **บล็อกโปรแกรมไว้**จนกว่าจะมีการกด |
| `OK_PUSH` | ตรวจสอบทันทีว่าปุ่มถูกกดอยู่หรือไม่ (คืนค่าจริง/เท็จ) โดยไม่หยุดรอโปรแกรม |

## เซนเซอร์ (Sensor)

อ่านและคาลิเบรตเซนเซอร์เส้น 6 ตัว รวมถึงเซนเซอร์วัดระยะอัลตราโซนิก

| บล็อก | คำอธิบาย |
| --- | --- |
| `ReadSensor` | อ่านค่าดิบ (analog) จากเซนเซอร์เส้นทั้ง 6 ตัว เก็บไว้ใช้ภายใน |
| `ReadCalibrate` | อ่านค่าเซนเซอร์เส้นแล้วแปลงเป็นสเกล 0-1000 ตามค่าที่คาลิเบรตไว้ |
| `F[ i ]` | อ่านค่าของเซนเซอร์เส้นตัวที่ i (0 ซ้ายสุด – 5 ขวาสุด) ต้องอ่านค่าเซนเซอร์ก่อนหน้านี้แล้ว |
| `Set  F[ i ]  to` | เขียนค่าทับเซนเซอร์เส้นตัวที่ i เอง — ใช้ทดสอบตรรกะเดินตามเส้นโดยไม่ต้องมีเซนเซอร์จริง |
| `sonar.ping_cm()` | อ่านระยะทางจากเซนเซอร์อัลตราโซนิกด้านหน้า หน่วยเซนติเมตร |
| `RefLineValue  x` | ตั้งค่าขีดแบ่ง (0-1000) ระหว่าง "เจอเส้น" กับ "ไม่เจอเส้น" ใช้กับฟังก์ชันเดินตามเส้นทั้งหมด |
| `TrackLineColor` | บอกไลบรารีว่าสนามเป็นพื้นดำเส้นขาว หรือพื้นขาวเส้นดำ เพื่อกลับค่าการอ่านให้ถูกต้อง |
| `CalibrateSensor  pauseTime  samples` | แกว่งหุ่นยนต์ผ่านเส้นระหว่างคาลิเบรต แล้วบันทึกค่า Min/Max ลง EEPROM ให้อัตโนมัติ |
| `SaveCalibrateToEEPROM` / `LoadCalibrateFromEEPROM` | บันทึก/โหลดค่า Min-Max ของเซนเซอร์เส้นที่คาลิเบรตไว้ จากหน่วยความจำถาวรของบอร์ด |
| `SensorValueMin` / `SensorValueMax` | ตั้งค่า Min/Max ของเซนเซอร์เส้นทั้ง 6 ตัวด้วยตัวเอง แทนการคาลิเบรตอัตโนมัติ |
| `SerialSensor` / `SerialCalibrate` / `SerialDistance` | แสดงค่าเซนเซอร์เส้น (ดิบ/หลังคาลิเบรต) หรือระยะอัลตราโซนิก ทาง Serial Monitor เพื่อดีบัก |

## ความเร็ว/PID (Speed & PID)

ปรับจูนความสมดุลของมอเตอร์และค่าคงที่ PID สำหรับการเดินตามเส้น

| บล็อก | คำอธิบาย |
| --- | --- |
| `setBalanceSpeed` / `setBalanceBackSpeed` | ปรับลดความเร็วมอเตอร์แต่ละข้างตอนเดินหน้า/ถอยหลัง แก้ปัญหาหุ่นยนต์วิ่งเอียง ตั้งแยกตามช่วงความเร็ว (SPD_10–SPD_100) |
| `setKpKd` | ตั้งค่าคงที่ Kp (ความไวตอบสนอง) และ Kd (การหน่วง) ของ PID เดินตามเส้น แยกตามช่วงความเร็ว |
| `ModeSpdPID` | เลือกวิธีจำกัดความเร็วมอเตอร์แต่ละข้างหลังคำนวณ PID เช่น จำกัด 0 ถึง Max หรือให้กลับทิศได้ |
| `SetCenter` | ตั้งค่าที่ใช้อ้างอิงตอนขยับเข้ากึ่งกลางเส้นก่อนเลี้ยว (ใช้คู่กับ ToCenter) |
| `PID  SpeedL  SpeedR  Kp  Kd` | คำนวณ PID จากตำแหน่งเส้นหนึ่งครั้ง แล้วสั่งมอเตอร์ทันที — เรียกซ้ำ ๆ ในลูปเพื่อเดินตามเส้นเอง |
| `readPosition` | คำนวณตำแหน่งของเส้นเทียบกับตัวหุ่นยนต์ (0 = ซ้ายสุด, 1500 = ขวาสุด) ใช้ภายในบล็อก PID |

## เลี้ยว/หมุน (Turning)

ตั้งค่าและสั่งเลี้ยว/หมุนโดยใช้เซนเซอร์เส้นเป็นตัวตรวจจับจุดหยุด

| บล็อก | คำอธิบาย |
| --- | --- |
| `TurnSpeedLeft` / `TurnSpeedRight` | ตั้งค่าความเร็วและเซนเซอร์ที่ใช้ตรวจจับตอนเลี้ยว **ต้องตั้งก่อน**ใช้ TurnLeft/TurnRight เสมอ |
| `SetTurnSpeed` | ตั้งความเร็วที่ใช้กับ SpinL / SpinL2 / SpinR / SpinR2 |
| `SetToCenterSpeed` / `Delay_c_F` | ตั้งความเร็ว และตัวหารเวลา ที่ใช้ตอนขยับเข้ากึ่งกลางเส้นด้วย ToCenter |
| `ToCenter` | ขยับหุ่นยนต์เข้าหากึ่งกลางเส้นก่อนเลี้ยว (ตั้งความเร็ว/เวลาไว้ก่อน) |
| `TurnLeft` / `TurnRight` | เลี้ยวซ้าย/ขวาจนกว่าจะเจอเส้น ตามเซนเซอร์ที่ตั้งไว้ใน TurnSpeedLeft/Right |
| `SpinL` / `SpinL2` / `SpinR` / `SpinR2` | หมุนอยู่กับที่ไปทางซ้าย/ขวาจนเจอเส้น มีให้เลือก 2 จังหวะการหมุนต่อทิศทาง |

## เดินตามเส้น (Line Follow)

บล็อกหลักของภารกิจ — เดินตามเส้นด้วย PID จนเจอเงื่อนไขที่กำหนด แล้วทำคำสั่งต่อทันที

| บล็อก | คำอธิบาย |
| --- | --- |
| `FD / BK / TL / TR / SL / SR  Speed, Time` | เดินหน้า / ถอยหลัง / เลี้ยวล้อเดียวซ้าย-ขวา / หมุนอยู่กับที่ซ้าย-ขวา ตามเวลาที่กำหนด (มีหน่วงเวลาในตัว) |
| `FF, FFC, FFC2, FFR, FFR5, FFR2, FFL, FFL0, FFL2, FFWhite, FFBlack` | เดินตามเส้นด้วย PID จนเจอ **ทางแยกแบบต่าง ๆ** (กว้าง/แคบ/ซ้าย/ขวา/กลาง/หลุดเส้น ฯลฯ) แต่ละแบบตรวจจับรูปแบบทางแยกต่างกัน แล้วทำคำสั่งที่เลือกไว้ทันที (หยุด/เลี้ยว/วิ่งต่อ) |
| `FFNUM` | เดินตามเส้นด้วย PID จนกว่าเซนเซอร์ตัวที่เลือก (0-5) จะเจอเส้น แล้วทำคำสั่งที่เลือก |
| `FF_DISTANCED` | เดินตามเส้นด้วย PID จนกว่าเซนเซอร์อัลตราโซนิกจะเจอสิ่งกีดขวางในระยะที่กำหนด (ซม.) แล้วทำคำสั่งที่เลือก |
| `FFTimer` | เดินตามเส้นด้วย PID ตามระยะเวลาที่กำหนด จะทำคำสั่งต่อท้ายหรือหยุดเฉย ๆ ก็ได้ |
| `TrackSelect` | ทำคำสั่งที่ทางแยกทันที — เป็นบล็อกเดียวกับที่บล็อกเดินตามเส้นด้านบนเรียกใช้ตอนจบ (หยุด/รอ/เลี้ยวซ้าย/เลี้ยวขวา/วิ่งต่อ) |
| `set_f  num` | ขยับซ้าย-ขวาให้หุ่นยนต์อยู่กึ่งกลางเส้นก่อนข้ามทางแยก โดยใช้เซนเซอร์ริมสองตัว ทำซ้ำได้ตามจำนวนที่กำหนด |

## เซอร์โว (Servo)

ควบคุมแขนกล (servo_base, ขา 12) และมือจับ (servo_gripper, ขา 14)

| บล็อก | คำอธิบาย |
| --- | --- |
| `servoSetup` | ต่อเซอร์โวแขนกลและมือจับเข้ากับขาสัญญาณ **ต้องเรียกก่อน**บล็อกเซอร์โวอื่นเสมอ |
| `servo  de1  de2` | ตั้งมุมแขน (de1) และมือจับ (de2) พร้อมกันในบล็อกเดียว |
| `arm_base  angle` / `arm_gripper  angle` | ตั้งมุมแขน หรือมุมมือจับ ทีละอย่างเอง (0-180 องศา) |
| `servo_up` / `servo_up45` / `servo_down` | ท่ายกแขนสำเร็จรูป 3 ระดับ — ยกสุด / ยกครึ่งหนึ่ง / วางลง |
| `servo_open` / `servo_close_small` / `servo_close_big` | ท่ามือจับสำเร็จรูป — อ้ามือจับ / หุบจับวัตถุชิ้นเล็ก / หุบจับวัตถุชิ้นใหญ่ |
| `Set  [ท่า]  to` | ปรับค่าองศาของแต่ละท่าสำเร็จรูปด้านบนเอง (s_up, s_up45, s_down, s_open, s_closesmall, s_closebig, s_ready) |
| `SerialServoControl` | ปรับมุมเซอร์โวแบบโต้ตอบผ่าน Serial Monitor (พิมพ์ "1 90" / "2 90") ใช้หาค่ามุมตอนคาลิเบรต — บล็อกโปรแกรมจนกว่าจะพิมพ์ exit |
